# Zasady zachowania

Te zasady obowiązują w zgłoszeniach, komentarzach i przy przeglądzie kodu
projektu Bezpieczna Gdynia.

- Rozmawiaj z szacunkiem, niezależnie od doświadczenia drugiej osoby.
- Krytykuj pomysł lub kod, bez atakowania jego autora.
- Nie publikuj cudzych danych osobowych. Nie tolerujemy nękania, gróźb
  ani dyskryminacji.

Opiekun projektu może poprosić o zmianę komentarza, usunąć szkodliwą treść
lub ograniczyć udział osoby, która łamie zasady. Poważne nadużycia można
zgłosić przez [narzędzia zgłoszeń GitHuba](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
Nie publikuj w zgłoszeniu wrażliwych danych innych osób.
